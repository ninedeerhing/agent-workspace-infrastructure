# 洞察日记 (Insight Journal) 模板

## 洞察记录

| 字段 | 内容 |
|------|------|
| **洞察 ID** | `INS-[YYYYMMDD]-[序号]` |
| **日期** | [YYYY-MM-DD] |
| **来源** | [任务/阅读/对话/复盘/其他] |
| **类型** | 最佳实践 / 反模式 / 跨域类比 / 技术发现 / 思维方式 |

## 洞察内容

**一句话描述**：
[用一句话概括你的发现]

**详细说明**：
[展开描述你的发现，包括具体上下文]

**触发事件**：
[是什么让你产生了这个洞察？]

## 适用范围

- **适用场景**：[这个洞察在什么情况下有效]
- **不适用场景**：[什么情况下不应套用]
- **前置条件**：[应用此洞察需要什么前提]

## 关联

| 关联类型 | 关联对象 |
