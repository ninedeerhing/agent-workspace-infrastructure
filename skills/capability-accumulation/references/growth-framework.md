# 个人成长与能力累计框架 — 设计文档

## 概述

本框架基于 Nous Research 的 [Hermes Agent](https://github.com/NousResearch/hermes-agent) 项目的核心设计哲学，将 AI 代理的六种能力累积模式转化为面向人类个人成长的系统化框架。Hermes Agent 是目前唯一具有内置学习循环的 AI 代理——它从经验中创建技能，在使用中改进技能，搜索自己的历史会话，并跨会话建立用户模型。

## 灵感来源：Hermes Agent 六大核心模式

### 模式 1：闭环学习 (Learning Loop)

```
经验 -> 技能创建 -> 使用中改进 -> 自我提示持久化 -> 跨会话回忆 -> 更多经验
```

本框架对应：经验捕获 -> 能力技能化 -> 渐进改进 -> Curator策展 -> 知识网络搜索

### 模式 2：技能系统 (Skills System)

SKILL.md 格式采用渐进式披露（3级加载）。Agent 通过 skill_manage 工具自主创建、更新、删除技能。v0.12+ 引入 Curator，以7天为周期自动评分、合并和裁剪技能库。

本框架对应：能力卡片 + 渐进式披露 + Curator策展循环

### 模式 3：记忆系统 (Memory System)

双层记忆架构：核心记忆（MEMORY.md 2,200字符）+ 全量历史（SQLite FTS5全文搜索）。字符限制强制策展，80%容量时触发合并，会话开始时注入冻结快照。

本框架对应：有界核心记忆 + 全量可搜索历史 + 80%合并触发

### 模式 4：个性化 (Personalization)

多层上下文文件：SOUL.md（人格）、USER.md（用户画像）、AGENTS.md（项目指令）。多profile配置隔离。

本框架对应：用户画像 + 学习风格 + 领域上下文

### 模式 5：度量可视化 (Insights)

/insights 命令提供使用统计和LLM生成的摘要分析。

本框架对应：能力雷达图 + 里程碑地图 + 投入产出分析

### 模式 6：自动化与委派 (Cron + Subagents)

内置Cron调度器 + 子代理委派系统。

本框架对应：定期复盘日程 + 成长委派 + 工具辅助分析

## 六层架构设计

```
第6层：生态连接  — 知识源管理 · 社区参与 · 导师追踪
第5层：自动化委派 — 定期复盘 · 习惯追踪 · 任务委派
第4层：成长度量  — 能力雷达 · 里程碑 · 投入产出
第3层：知识网络  — 跨域链接 · 知识合并 · 定期策展
第2层：能力技能化 — 经验->方法论 · 渐进改进 · Curator循环
第1层：经验捕获  — 决策日志 · 事后复盘 · 洞察日记
```

## 关键设计决策

### 决策 1：有界记忆 vs 无限存储
选择Hermes的双层记忆模型（有界核心 + 无限全量）。强制策展保证知识质量，全量可搜索确保不丢失信息。

### 决策 2：渐进式披露 vs 全量加载
选择3级渐进式披露，降低认知负担，先概览再深入符合人类学习模式。

### 决策 3：定期策展 vs 随时维护
选择7天周期的Curator模式。批量处理更高效，固定节奏建立习惯，有时间距离后更客观。

### 决策 4：度量辅助 vs 直觉主导
度量作为客观视角，但不替代主观感受。避免"指标驱动"的成长焦虑。
