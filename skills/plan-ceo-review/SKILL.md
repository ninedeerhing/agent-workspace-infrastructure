# Plan CEO Review — 创始人/CEO 审查

## 定位

以创始人/CEO 的视角审查产品方案。关注范围控制、资源分配和战略对齐。输出四种范围决策模式。

## 触发条件

- `office-hours` 或 `brainstorming` 完成
- 有一个产品方案需要决策
- 需要从商业/战略角度做权衡

## 四种范围模式

### 模式 1：扩展范围（Expand）

**适用**：当前方案偏保守，有明确的未利用机会。

**信号**：
- 竞争对手在做但你忽略的事
- 用户明确需要但你排除的功能
- 技术储备可以轻松支持的扩展

**风险**：资源分散、延迟交付

### 模式 2：选择性扩展（Selective Expand）

**适用**：保持核心范围，仅在特定高价值方向扩展。

**信号**：
- 某个功能对特定用户群有 10x 价值
- 扩展与核心竞争力高度协同

### 模式 3：保持范围（Maintain）

**适用**：当前方案范围合理，聚焦核心价值。

**信号**：
- 范围与资源匹配
- 核心价值清晰
- 无明显的范围问题

### 模式 4：缩减范围（Reduce）

**适用**：方案过大，需要砍功能保核心。

**信号**：
- 时间线不切实际
- 多个"可有可无"的功能
- 核心价值被稀释

**原则**：砍掉半功能，保留全功能。

## 审查问题

1. 这个方案 6 个月后的回顾会是什么样？
2. 如果只能做一件事，哪件事？
3. 最大的假设是什么？怎么验证？
4. 竞争对手会怎么回应？
5. 用户愿意为此付费吗？

## 反模式 / 红牌

| 反模式 | 说明 |
|--------|------|
| 无数据支撑的判断 | 黄牌。决策需要有依据 |
| 忽视竞争 | 红牌。必须考虑竞争响应 |
| 情绪化决策 | 黄牌。冷静分析，不凭感觉 |
| 不标注假设 | 红牌。关键假设必须明确标注 |
